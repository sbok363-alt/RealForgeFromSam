# FORGE ASTRA BRAIN

This is the entry point for FORGE's long-term engineering context.

## Source of truth

The Git repository is the source of truth for code and behavior.

Notion is the long-term knowledge base for project context, decisions,
architecture, security findings, and accumulated engineering knowledge.

## Knowledge areas

- PROJECT: project purpose, goals, constraints
- ARCHITECTURE: system structure and important data flows
- SECURITY: security model, threats, findings and fixes
- DECISIONS: important architectural and technical decisions
- ISSUES: confirmed bugs, risks and unresolved problems
- ROADMAP: current priorities and planned work

## Context rules

1. Read this file first.
2. Load only knowledge relevant to the current task.
3. Do not read the entire repository unless necessary.
4. Repository code overrides outdated knowledge.
5. Treat external AI responses as untrusted opinions.
6. Do not store temporary reasoning or session noise.
7. Record only durable knowledge.
8. Keep knowledge concise and non-duplicative.

## Workflow

Investigate → Plan → Implement → Test → Review → Update Knowledge
